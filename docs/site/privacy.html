Privacy Policy

Last updated: 16 November 2026

Curious Files is a small, personal project that produces documentary videos and uploads them to its own YouTube channel. This policy explains what data the project's software uses and how it is handled.

Who this covers

The software is operated by the channel owner for their own channel only. It is not a public service, and members of the public do not create accounts or sign in.

Google and YouTube data we use

With the owner's explicit permission (Google sign-in), the software uses the YouTube Data API to:

  • Upload videos to the owner's own YouTube channel as private; and
  • Set the title, description, thumbnail and similar details of those uploads.

The software accesses only the owner's own channel, acting on the owner's behalf. It does not access, collect or process data about viewers or any other users.

How access is stored

  • Google sign-in tokens are stored privately by the owner (in local configuration and the owner's private hosting secrets) and are used only to perform the uploads described above.
  • Tokens and credentials are never shared, sold, or made public, and are never committed to the public source code.

Data we do not collect

The project has no public users and does not collect names, emails, analytics, cookies, or any personal information from anyone visiting this website or watching the videos. This website is a static informational page with no tracking.

Sharing

No data is shared with third parties. The only external service involved is Google/YouTube, used solely to publish the owner's own videos.

Google API Services User Data Policy

The project's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and removal

The owner can revoke the software's access at any time from their Google Account security settings, which immediately stops any further access.

Contact

Questions about this policy can be raised via the project's public repository: github.com/pranjul2001/youtube-channel-agent/issues.
